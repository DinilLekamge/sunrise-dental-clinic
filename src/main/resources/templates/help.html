Help for clinic staff

Step-by-step instructions for the tasks you will use every day.

  1. Open the clinic system in your browser.
  2. Type the username and password given to you by the administrator.
  3. Select Sign in. You are taken to the dashboard for your role.
  4. If the message says the details are incorrect, check the caps lock key and try again. Ask the administrator if your account has been deactivated.

  1. Select Patients in the menu.
  2. Select Register patient.
  3. Type the name, address and contact number.
  4. Select Save patient. Any field that is wrong is shown in red.

  1. Register the patient first if this is a new patient.
  2. Select Appointments, then Register appointment.
  3. Choose the patient, the dentist and the treatment.
  4. Choose the date and the time. The date cannot be in the past.
  5. Select Save appointment. The system creates the appointment number.
  6. If the dentist is already booked at that time the system shows a message and nothing is saved. Choose another time or another dentist.

  1. Select Appointments.
  2. Type the appointment number in the search box and select Search by number.
  3. The full appointment and patient details are shown.
  4. You can also filter the list by dentist.

  1. Open the appointment from the list or by searching for its number.
  2. Select Update appointment to change the dentist, treatment, date, time or status.
  3. Select Cancel appointment to cancel it, then confirm. The record stays in the system with the status CANCELLED.

  1. Open the appointment.
  2. Select Generate bill. The total is the treatment fee plus the consultation fee.
  3. The receipt page opens with the bill number and all the details.
  4. Select Print receipt and use your browser print dialog.
  5. Only one bill can exist for each appointment. If a bill already exists, select View receipt instead.

  1. Select Log out at the top right of any page.
  2. You are returned to the login page and your session is closed.
